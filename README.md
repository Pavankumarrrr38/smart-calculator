# Smart Calculator

A simple, interactive command-line calculator built with Python. It evaluates standard mathematical expressions and includes built-in error handling for a smooth user experience.

## Features
* **Continuous Input:** Keeps running until you type `exit`.
* **Mathematical Evaluation:** Handles order of operations and parentheses.
* **Error Handling:** Gracefully catches syntax errors, unknown variables, and division by zero.

## Prerequisites
* Python 3.x installed on your system.
